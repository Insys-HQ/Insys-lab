방안 1 — 가이드 카메라 분리형2카메라

헤더에 측정 전용 가이드 카메라(+레이저 포인터)를 별도 장착. 거리·기울기·위치를 1회 측정으로 확정하고 4축 스테이지가 한 번에 법선 정렬하는 방식.
  1. PCB 반입 · 정지 — 컨베이어 정지신호 수신(PLC 접점)
  2. 가이드 카메라 측정 — 거리 · 기울기 · 위치 (레이저 보조로 Z 확정)
  3. 보정량 계산 — X · Y · Rx · Ry 산출
  4. 4축 스테이지 구동 — 검사카메라 법선 정렬 (1회 이동)
  5. 검사 촬영 — 검사카메라 + 링 · 동축 조명
  6. 딥러닝 양불판정 — 납땜 상태 분류
  7. 화면 표시 · MES 전송 — 양품 / NG 구분 표시, 검사이력 전송
측정 · 정렬(1차 목표)구동 · 촬영판정 · 출력

장점 · 유의점

장점

  • 1회 측정 → 1회 이동, 택트타임 짧음
  • 넓은 화각으로 초기 탐색 유리
  • 레이저 보조로 거리(Z) 측정 정확

유의점

  • 가이드 카메라 · 레이저 추가 비용 +50~80만원
  • 두 카메라 간 좌표 변환 캘리브레이션 필요(복잡)
  • 카메라 간 정합 오차가 정렬 정밀도에 직결

방안 2 — 검사카메라 엣지 활용형1카메라

별도 가이드 카메라 없이 검사카메라의 프리뷰 영상에서 PCB 외곽 엣지를 검출해 X·Y·θ 산출, 원근 왜곡으로 기울기, 초점 샤프니스로 거리를 추정. 보정 이동 후 재촬영으로 오차를 수렴시키는 반복 구조.
  1. PCB 반입 · 정지 — 컨베이어 정지신호 수신(PLC 접점)
  2. 프리뷰 촬영 — 검사카메라 · 보조조명
  3. 엣지 검출 · 자세 추정 — X · Y · θ · 기울기 · 거리
  4. 스테이지 보정 구동 — 법선 정렬 이동
  5. 오차 확인 — 허용범위 수렴 판정↻ 오차 초과 시 프리뷰 촬영부터 반복 (최대 2회)
  6. 검사 촬영 — 검사조명 ON · 고해상도
  7. 딥러닝 양불판정 — 납땜 상태 분류
  8. 화면 표시 · MES 전송 — 양품 / NG 구분 표시, 검사이력 전송
측정 · 판단(1차 목표)구동 · 촬영판정 · 출력

장점 · 유의점

장점

  • 카메라 1대 — 추가 비용 없음
  • 단일 광축 — 캘리브레이션 단순
  • 부족 시 가이드 카메라만 추가해 방안 1로 무손실 전환

유의점

  • 거리(Z) 추정 정확도 낮음 → 반복 수렴으로 보완
  • 반복 시 택트타임 +1~2초
  • 조명 조건에 따른 엣지 검출 안정성 확인 필요
  • 검사렌즈 화각에 PCB가 들어와야 성립

미팅 협의 포인트

  1. 검사카메라 화각(FOV)에 PCB 전체(장축 100mm)가 들어오는 렌즈로 갈지, 부분 촬영(분할 검사)으로 갈지 — 방안 2 성립의 핵심 전제
  2. 반복 수렴에 따른 택트타임 증가(+1~2초) 허용 여부
  3. 현장 조명 조건에서 PCB 외곽 엣지가 안정 검출되는지 — 보유 카메라로 간이 테스트 진행
