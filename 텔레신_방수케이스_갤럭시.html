텔레신 방수케이스 사용 가이드 (갤럭시)

v1.0
핵심: 수심 20m 방수(IP68) 케이스입니다. 폰을 넣고 버클 5개 잠금 → 진공 펌핑 3~4회로 밀폐한 뒤, 블루투스 리모컨 버튼으로 촬영합니다.
모델 P4-WTP-06 · 안드로이드(갤럭시) 기준으로 정리했습니다.
※ 갤럭시 설정 메뉴 이름은 기종·One UI 버전에 따라 다를 수 있습니다. 설명서 원문에 없는 갤럭시 메뉴 경로는 참고로 표시했습니다.

블루투스 연결

  1. 케이스 촬영 버튼 2초 길게 → 전원 ON, 표시등 깜빡임(페어링 모드)
  2. 갤럭시 설정 → 연결 → 블루투스 참고
  3. TELESIN_SDC 선택
아이폰 전용 '확대/축소(손쉬운 사용)' 설정은 갤럭시에서는 필요 없습니다.

사용 전 폰 설정

  1. 화면 자동 꺼짐: 설정 → 디스플레이 → 화면 자동 꺼짐 시간 → 가장 긴 시간 참고
    원문은 '안 함'이나, 갤럭시는 '안 함' 항목이 없는 경우가 많습니다.
  2. 방해 금지 모드 켜기: 설정 → 알림 → 방해 금지 참고
  3. 기본 카메라 앱 실행

전원·절전

전원 ON촬영 버튼 2초 → 표시등 깜빡임, 페어링 모드
전원 OFF켜짐/절전 중 촬영 버튼 2초 → 표시등 3번 깜빡이고 꺼짐
자동 절전페어링 후 60분 조작 없음
연결 끊김폰 설정·거리·블루투스 OFF → 절전, 30분 후 자동 꺼짐
절전 해제아무 버튼 누름 (마지막 연결 폰 블루투스가 켜져 있으면 자동 재연결)
미연결전원 ON 후 2분 내 페어링 안 되면 자동 꺼짐

케이스에서 폰 꺼내기

  1. 진공 밸브 커버를 풉니다.
  2. 검은 고무 패킹을 눌러 압력을 뺍니다.
  3. 압력이 빠진 뒤 버클을 풉니다.
순서를 지키지 않으면 음압으로 흡착되어 열리지 않습니다.

방수 테스트 결과

휴지가 마름 → 방수 정상 / 휴지가 젖음 → 즉시 고객센터 문의

바닷물 사용 후 관리

  1. 폰을 빼고 잠근 상태로 민물에 10분 담그기
  2. 흐르는 수돗물에 5분 헹구기
  3. 수건으로 닦기 (헤어드라이어·히터 금지)
  4. 내부는 방수 안 됨 – 내부는 절대 헹구지 않기 (회로 손상)

충전

  1. 제공된 충전 케이블의 접점을 왼쪽 측면 충전 포트에 연결
  2. 반대쪽은 USB 전원에 연결 (약 2시간)
충전 중 수건·옷으로 덮지 마세요(화재 위험).

주의사항

  • 분해·손상 금지, 변형·파손 시 즉시 사용 중단
  • 낙하, 고온, 단락(쇼트) 환경 피하기
  • 온천, 정체불명 액체, 부식성 액체에서 사용 금지
  • 건조하고 통풍 잘 되는 곳에 보관, 어린이 손이 닿지 않게
  • 보증기간: 수령일로부터 6개월
