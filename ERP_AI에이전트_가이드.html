ERP AI 에이전트 도입 가이드 v2.3 인시스 AI혁신 연구개발실 · 2026-11-24

ERP에 이미 있는 AI 비서를 채우고, 엔진을 올리고, 손을 단다

직원이 자연어로 지시하면 AI가 ERP 절차를 직접 진행(조회 → 입력안 → 직원 확인 → 입력 → 결재선 확인 → 직원 확인 → 상신)하는 것이 목표입니다.

목표 모습

  1. 비서가 정확한 메뉴 경로와 절차를 답한다
  2. 영수증·엑셀을 주면 비서가 입력안을 제안하고 직원은 확인만 한다
  3. 결재는 정해진 결재선대로 간다
  4. 비서가 못 한 일은 개선요청으로 자동 정리되어 개발자에게 간다
  5. 영상·퀘스트는 필수가 아니라 필요할 때 비서가 안내한다

결재선이 엉뚱하게 가는 원인

  • 결재선 정책 68건 대부분의 첫 단계 = 직속 상사(보고선)
  • 부서 53개 중 부서장 미지정 28개, 상위 부서 미지정 46개
  • 등록 회사 27곳 중 부서가 있는 회사 15곳, 직원 0명 회사 11곳
  • 조건 불일치 시 기본 결재선 5단계(보고선 → 회계 확인 → 회계 부서장 → CFO → 대표)

ERP 전체 조사 결과 (화면 208개·업데이트 247건·개선요청 487건)

  • 자동 수집(CODEF: 카드·홈택스·통장·4대보험)·규칙 분류·할일 자동 생성·AI 초안 기능은 이미 풍부
  • 문제는 예외 적체: 카드 확인 필요 326건, 세금계산서 처음 보는 거래처 179건, 부가세 「고칠 것」 563건, 미업로드 계좌 107개
  • 기초 데이터 공백: 부서장 28·상위 부서 46·급여계좌 80명
  • 개선요청 처리율 약 93% (완료 451/487), 거의 매일 배포
  • CODEF는 데모 단계 — 하루 100회 한도를 4개 수집이 함께 사용

트랙 A. 인시스가 직접 (즉시, 비용 없음)

할 일위치담당
A1. 지식 문서 등록: 메뉴 지도·결재선·주요 절차·권한사이트 설정 › AI 설정 › 지식 문서연구개발실
A2. 봇 시스템 프롬프트 강화 (비서·회계·인사)AI 설정 › 봇 카탈로그 › 봇 편집연구개발실
A3. 「지식 반영 테스트」로 대표 질문 검증AI 설정 › 지식 문서연구개발실
A4. 지식 공백 리포트 주 1회 검토 → 문서 보강AI 설정 › 모델·사용량연구개발실
A5. 조직 정비 (조직·결재선 탭)인사 › 부서, 인사 설정인사 담당 + 연구개발실

트랙 B. 개발자에게 요청 (개선요청서 송부 완료)

요청이유
B1. 모델 상향: gpt-4o-mini → GPT-5 또는 Claude Sonnet 추가답변 품질의 핵심, 개발자만 변경 가능
B2. 고객사별 모델 선택 허용현재 모든 고객사 공통
B3. 결재선 판정(이 거래는 누구에게?)을 비서 도구로상신 전 결재선 확인
B4. 카드 경비 용도 일괄 입력 도구가장 반복 많은 입력
B5. 비서 접근 모듈 확대(급여·현장관리·관리회계)권한 상속 전제
B6. 오류 시 개선요청 초안 자동 작성개발 AI가 바로 처리
B7. 첨부파일(엑셀·워드·PDF·PPT·HWP) 자동 MD 변환·저장AI가 첨부를 정확히 읽고 입력안·지식 문서로 활용
B8. 예외 목록 추천 도구 (카드 미분류·세금계산서·근태 확인 필요)추천안+근거, 확정은 사람
B9. 월간 루틴 에이전트 (근태 → 급여 → 명세서 → 손익 보고)4대 업무 자동 점검
B10. CODEF 정식 전환 검토하루 100회 공동 한도
ERP MCP 서버 (ChatGPT·Claude 연결용)외부 AI에서 자연어로 ERP 업무 실행

트랙 C. 개인용 AI 시범

  • ChatGPT Business 6석 시범 구독 중 → 경영지원실 핵심 인원
  • 바로 가능: ERP 엑셀 내려받기 → ChatGPT에 올려 근태 예외·손익 초안 (사번 등 최소 항목만)
  • ERP MCP 서버가 오면 인시스 IT담당자가 ChatGPT 개발자 모드에서 테스트 후 워크스페이스 배포
  • 같은 MCP 서버를 Claude에도 연결해 비교 가능
  • Claude 프로젝트 「ERP AI 에이전트」에 지식문서·가이드·요청서 탑재 완료
