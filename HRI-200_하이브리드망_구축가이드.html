HRI-200 1대 = 노드 1개입니다. 3대를 각각 따로 등록하며, 각 등록은 해당 HRI-200의 S/N으로 합니다. 룸은 기존 DS0ARC 룸(48182)을 그대로 사용합니다.

2 등록 절차 — S/N 전송부터 회신까지 (3대 각각 반복)

  1. S/N 확인 — HRI-200 본체 뒷면 스티커의 Serial Number를 대소문자 그대로 메모 (3대 모두 → 3장 표)
  2. 등록 사이트 접속 — 아래 "멤버 등록" 링크를 열어 등록용 이메일 주소를 입력하고 Send 클릭
    📝 멤버 등록 (이메일 입력 · S/N 전송)🔒 로그인 후 이용 WIRES-X 메인 → 좌측 Member registration
    주소는 반드시 https://www.yaesu.com/… 처럼 www.가 있어야 합니다. yaesu.com/…(www 없음)으로 열면 404가 납니다. 그래도 안 열리면 위 "WIRES-X 메인"에서 좌측 Member registration을 눌러 들어가세요.
  3. 등록 URL 메일 수신 — 몇 분 안에 도착. 안 오면 스팸함 확인
  4. 메일의 URL 클릭 → 약관 — 라이선스 동의 체크 → Agree and proceed
  5. 등록 양식 입력 — 모든 항목 입력, HRI-200 Serial Number/RADIO ID 칸에 S/N 입력 (3번 입력표 참조) → Submit
  6. 회신 대기 2~3 영업일 — 승인 메일에 Node ID · Room ID가 옴. 보관 (4번 기록표)
  7. 로그인 — WIRES-X 사이트 우측 상단 Member Login → 소프트웨어 다운로드
🔒 로그인 필요 : 등록 완료 후 받는 User ID/Password로 로그인해야 열리는 페이지(Node owner 다운로드 등)는 로그인하지 않으면 연결되지 않고 로그인 화면이 나옵니다. 먼저 Member Login 하세요.
출처 : YAESU WIRES-X 매뉴얼 "User Registration" — 이메일 전송 → 등록 URL → 약관 동의 → 입력 → 2~3 영업일 후 Node ID·Room ID 메일 수신. (매뉴얼 7쪽)

5 설치·설정 (승인 후)

  1. HRI-200 드라이버 먼저 설치 → WIRES-X 소프트웨어 설치 → PC 재시작 → USB 연결 (Node owner 페이지 다운로드 🔒 로그인 후 이용)
  2. 연결 — PC ↔ USB, RADIO 1 ↔ 무전기(CT-174 10핀 / FM 6핀은 CT-175)
  3. 설정 — Serial/Radio ID = S/N, DTMF ID = Node ID, Modulation RX:FM – TX:FM, Return to Room 48182
  4. 시작 — 소프트웨어 먼저 실행 → 무전기 [D/X]+[GM] 누른 채 전원 ON(2초) → "HRI-200" 표시

세부 화면은 교육 슬라이드의 해당 장을 보세요 (중복 설명 생략).

B-1 연결·설치 B-2 설정값 B-3 켜기·끄기
매뉴얼 지원 기종표에는 FTM-510D가 없습니다. 무전기는 현장 운용 기준으로 연결합니다.
