DS0ARC룸 개설 노드기존 등록이번 신청 대상 아님 (Node 38182)
HL0FRC·DS0ARC·DS0ARC/M은 대한적십자사 재난대응봉사회 무선국(호출부호 끝 RC = Red Cross)이며, 허가 신청과 관리는 HL2TLS(기술팀장)가 담당합니다.
HRI-200 1대 = 노드 1개이며 노드 식별은 HRI-200의 S/N입니다(매뉴얼 26쪽: Serial No는 변경 불가). 룸은 기존 DS0ARC 룸(48182)을 그대로 사용합니다.
PDN으로 이미 가입한 경우 (HL2TLS) : PDN 등록은 무전기 Radio ID에 대한 것이고, HRI-200은 S/N이 다른 별개 장치입니다. YAESU에 S/N이 등록되어 있지 않으므로 HRI-200 S/N 등록은 필요합니다. 새로 "회원가입"을 처음부터 다시 하는 개념이 아니라 이 S/N에 Node ID를 발급받는 절차입니다.
다만 "기존 회원 정보로 S/N만 추가"하는 전용 화면이 있는지는 YAESU 공식 문서에서 확인하지 못했습니다. 다른 운용자 사례(xarc.us)는 두 번째 HRI-200을 새 Node/Room ID·새 로그인으로 등록했고, YAESU에 새 등록 링크를 요청했습니다.

2 등록 절차 — S/N 전송부터 회신까지 (3대 각각 반복)

  1. S/N 확인 — HRI-200 본체 뒷면 스티커의 Serial Number(영문·숫자 8자리, 2번째 글자는 영문, 예: 0A000000)를 메모. 숫자 0/영문 O, 숫자 1/영문 I 혼동 주의. 무전기 S/N이 아님 (3대 모두 → 3장 표)
  2. 등록 사이트 접속 — 아래 "멤버 등록" 링크를 열어 등록용 이메일 주소를 입력하고 Send 클릭 — 이 페이지에는 양식이 없고, 이메일로 온 URL에서 양식을 입력합니다 (로그인 불필요)
    📝 멤버 등록 (이메일 입력) WIRES-X 메인 → 좌측 Member registration
    이 링크는 이전 RC-NET 가이드의 등록 링크와 동일한 주소입니다. 안 열리면 이전 가이드(rcnet_guide.html)의 "멤버 등록" 링크를 누르거나, 위 "WIRES-X 메인"에서 Member registration으로 들어가세요.
  3. 등록 URL 메일 수신 — 자동 발송 메일. 안 오면 스팸함·이메일 오타 확인 후 문의(Contact us) (YAESU 페이지 안내)
  4. 메일의 URL 클릭 → 약관 — 라이선스 동의 체크 → Agree and proceed
  5. 등록 양식 입력 — 모든 항목 입력, HRI-200 Serial Number/RADIO ID 칸에 S/N 입력 (3번 입력표 참조) → Submit
  6. 회신 확인 — 제출 직후 접수 확인 메일이 오는지 확인 (없으면 7번 점검표)
  7. 회신 대기 2~3 영업일 — 승인 메일에 Node ID · Room ID가 옴. 보관 (4번 기록표)
  8. 로그인 — WIRES-X 사이트 우측 상단 Member Login → 소프트웨어 다운로드
🔒 로그인 필요 : 등록 완료 후 받는 User ID/Password로 로그인해야 열리는 페이지(소프트웨어 다운로드 등)는 로그인하지 않으면 연결되지 않습니다. 먼저 Member Login 하세요. (등록 페이지 자체는 로그인 없이 열립니다.)
출처 : YAESU WIRES-X 매뉴얼 "User Registration" — 이메일 전송 → 등록 URL → 약관 동의 → 입력 → 2~3 영업일 후 Node ID·Room ID 메일 수신. (매뉴얼 7쪽)

7 점검 · 문제 해결

증상조치
등록 URL 메일이 안 옴스팸함 확인 → 이메일 오타 확인 → 다시 Send
이미 등록된 이메일이라고 나옴다른 이메일로 등록하거나 문의 양식에 콜사인 · HRI-200 S/N · 기존 Node ID(5자리)를 적고 "이 S/N의 Node/Room ID 등록 링크"를 요청

3일 지나도 승인 메일 없음 · 문의스팸함 확인 후 WIRES-X 문의(Contact us) 양식 이용 — 이름·이메일 필수, 등록 완료한 경우 5자리 Node ID 입력란이 있음 (휴대폰 메일 주소는 사용 불가)
ONLINE이 안 됨드라이버 먼저 설치했는지, COM port 선택, 소프트웨어를 무전기보다 먼저 시작했는지 확인
