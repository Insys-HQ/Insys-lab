ERP MCP 개선요청 R10v1.0

ERP MCP 개선요청 — 역할·담당자 배정 도구 (R10)

버전 v1.0작성일 2026-11-27 인시스 AI혁신 연구개발실ys.kim@in-sys.co.kr
관련: 「ERP_AI에이전트_개선요청서_v1.3」 R3(MCP 서버)·3-4(쓰기 안전 규칙)에 추가 · 개인정보: 담당자 이름 미기재
결론: 2026-11-26 담당자 배정 건은 ERP MCP가 아닌 브라우저 화면 조작으로 처리됨. 해결은 테이블 쓰기 권한이 아니라 전용 도구(propose → confirm) 추가.

1. 발생 건 (2026-11-26)

항목내용
요청기능 카탈로그에서 직원 1명을 특정 계열사 회계 담당자로 추가
처리 방식ERP MCP 미사용 → Claude in Chrome(브라우저 화면 조작)
처리 경로기능 카탈로그(/portal/features) › 회계·세무 담당 › 담당자 연필(배정 범위) › 회사 체크 › 범위 저장
실행 권한요청자(관리자)의 Chrome 로그인 세션
결과회사 범위 9개사 → 10개사. 같은 회사에 기존 담당자 1명(공동 담당)

브라우저로 처리된 이유

  1. 쓰기 도구 없음: MCP 쓰기는 propose_* 8종뿐 — 입금 맞추기, 카드 계정, 일정, 지출결의서 초안, 메일, 세금계산서 분류, 할일 계획, 위키. 역할·담당자 배정 도구 없음
  2. 조회도 불가: query_table 조회 가능 표에 역할 배정·기능 카탈로그 표가 없음 → 처리 후 MCP로 검증 불가
  3. Claude가 도구 부재를 먼저 알리지 않고 브라우저로 진행 (지침 보완 필요 → 4장)

브라우저 처리의 문제점

문제영향
MCP 감사 로그(요청문·도구·입력·결과) 미기록AI로 권한을 바꾼 이력 추적 어려움
서버 쪽 미리보기·확인 단계 없음좌표 클릭 오류 시 다른 사람·회사에 잘못 반영 위험
하루 실행 횟수 제한 미적용대량 변경 통제 불가
요청자 PC의 Chrome 세션 필요다른 직원·모바일·ChatGPT에서 같은 처리 불가

2. 결론: 「테이블 쓰기 권한」이 아니라 「전용 도구 추가」

방안판단이유
A. 역할 배정 표에 AI 직접 쓰기 권한비추천「범위 저장」의 후처리(권한 반영, 알림, 변경 이력)를 건너뛸 수 있음. 권한 변경은 최고 위험 쓰기
B. 전용 도구 (propose → confirm)추천기존 MCP 쓰기 방식과 동일. 미리보기·확인·횟수 제한·감사 로그 자동 적용
C. 조회 표 공개 (query_table 추가)B와 함께처리 전후 검증, 중복 담당 점검에 필요

3. 요청 도구 정의

도구명기능입력출력쓰기
list_feature_roles기능 카탈로그 역할 목록시스템·키워드역할 ID, 이름, 담당자 수아니오
list_role_assignments역할별 담당자·회사 범위 조회역할 ID 또는 직원, 회사담당자(사번), 회사 범위, 지정일, 지정자아니오
propose_role_assignment담당자 추가 / 회사 범위 추가·제외 제안역할 ID, 직원, 회사 목록, 동작(add / add_scope / remove_scope)변경 전·후 회사 범위, 경고, action_id예(제안)
confirm_proposal (기존)제안 실행action_id반영 결과 (「범위 저장」과 동일 처리)예(확정)

미리보기 필수 경고

  1. 같은 회사에 이미 다른 담당자 있음 (공동 담당 여부 확인) — 이번 건 사례
  2. 해당 직원이 그 회사 소속 아님 (계열사 겸임 여부)
  3. 직원 퇴사·휴직 상태
  4. 변경 회사 수가 많음 (예: 5개사 이상)

4. 권한·안전 규칙

  1. 권한 상속: 기능 카탈로그 배정 권한 보유자(테넌트 관리자 등)만 동작, 그 외 forbidden
  2. AI 제외 대상: 시스템 관리자 역할 부여, 본인 권한 상승, 급여 조회 등 민감 역할 부여 → 거부 후 화면 처리 안내
  3. 담당자 제거는 1차 범위 제외 (회사 범위 축소만 허용할지 협의)
  4. 하루 AI 실행 상한 (예: 10건), 1회 1명·1역할
  5. 감사 로그: 사용자, 시각, 클라이언트(Claude/ChatGPT/ERP 비서), 변경 전·후 범위
  6. 변경 시 대상 직원에게 ERP 알림 (화면 처리와 동일)

인시스 측 지침 보완 (Claude 공통 지침에 추가) 

- ERP 쓰기 요청은 ERP 도구(propose_* → confirm_proposal)로 먼저 처리한다.
- 맞는 ERP 도구가 없으면 브라우저로 바로 진행하지 말고
  "ERP 도구에 이 기능이 없음 → 브라우저 화면 조작으로 처리 가능"을 먼저 알리고 확인을 받는다.
- 브라우저로 처리한 쓰기는 경로·변경 전후·시각을 답변에 남긴다.

5. 개발사 전달용 이슈 

[ERP-이슈] MCP에 기능 카탈로그 역할·담당자 배정 도구 없음
- 발생일시 : 2026-11-26
- 클라이언트 : Claude (ERP MCP 연결)
- 모듈·메뉴 / 경로 : 포털 › 기능 카탈로그 (/portal/features) › 역할 › 담당자 배정 범위
- 사용자 맥락 : 테넌트 관리자, 인시스
- 재현 절차 : 1) Claude에 "○○ 직원을 △△회사 회계 담당자로 추가해줘" 요청
              2) MCP 도구 목록에 해당 쓰기 도구 없음, query_table에도 역할 배정 표 없음
              3) 브라우저 화면 조작으로만 처리 가능
- 기대 결과 : list_role_assignments 조회 → propose_role_assignment 미리보기 → confirm_proposal 실행, 감사 로그 기록
- 실제 결과 : MCP로 조회·변경 모두 불가 (감사 로그 없음)
- 영향 범위 : 계열사 담당자 배정·변경 업무 전체 (회계·세무, 인사, 급여 등 역할)
- 우선순위 : 중간 (권한 변경은 위험도 높아 안전 규칙과 함께 적용)

회신 요청

  1. 역할 배정 표 이름과 「범위 저장」 시 후처리 내용 (권한 반영·알림·이력)
  2. 3장 도구 제공 가능 여부·일정
  3. 4장 AI 제외 대상(민감 역할) 목록을 테넌트 설정으로 둘 수 있는지
