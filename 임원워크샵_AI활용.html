5클로드 코드 소개10분

무엇인가

채팅처럼 대화하지만, 내 PC의 파일을 읽고 문서를 만들고 명령까지 실행하는 AI 작업 도구입니다. 터미널, 개발도구(IDE), 데스크톱 앱, 웹에서 쓸 수 있습니다.

구분클로드 채팅클로드 코드
결과물대화로 답변파일로 직접 저장
PC 파일업로드한 것만연결한 폴더 전체
반복 작업매번 요청예약 작업, 자동 실행
규칙 기억대화 안에서설정 파일에 고정
데스크톱 앱에 로그인하면 Code 탭에서 바로 시작할 수 있습니다 (유료 플랜 필요).
6에이전트 설정·사용법15분

에이전트와 서브에이전트

구분에이전트(메인)서브에이전트
역할대화하며 전체 지휘맡은 한 가지 작업만 수행
맥락전체 대화를 앎새로 시작, 지시문만 앎
결과사용자와 직접 소통요약만 메인에게 보고

만드는 법

말로 시키면 파일을 대신 만들어 줍니다. 직접 만들 때는 아래 파일 1개면 충분합니다.

예시: 문서 검토 에이전트
---
name: doc-reviewer
description: 문서의 오탈자, 숫자 불일치, 버전 표기 누락을 점검. 문서 작성 후 사용.
tools: Read, Grep, Glob
model: sonnet
---

당신은 문서 검토 담당입니다. 오류를 우선순위별로
(필수 수정 / 권장 수정 / 제안) 정리하고 수정 예시를 함께 제시하세요.

저장 위치와 호출

  • 내 전체 프로젝트: ~/.claude/agents/ , 현재 프로젝트만: .claude/agents/
  • 호출: "doc-reviewer로 이 보고서 검토해줘" 또는 @ 멘션
  • 여러 에이전트에게 동시에 조사를 맡기는 병렬 작업 가능
7하네스 소개10분

하네스란

AI가 안전하고 일관되게 일하도록 감싸는 규칙·도구·권한의 틀입니다. 말로 부탁하는 수준을 넘어 "항상 지키게" 만드는 장치입니다.

구성 요소역할
CLAUDE.md매번 자동으로 읽는 우리 회사 규칙 문서
Skills반복 업무를 /명령어로 패키징
Hooks파일 저장·실행 전후에 검사 스크립트 자동 실행
Subagents역할별 보조 에이전트
MCP·커넥터메일·일정·Drive 등 외부 도구 연결
권한 모드승인 후 실행(Manual)부터 자동 실행까지 단계 조절
예: "문서에는 항상 버전번호와 담당부서를 표기"를 CLAUDE.md에 한 번 적어 두면 모든 문서에 적용됩니다.
8예시 시연15분
#시나리오시연 문장
1메일 정리"오늘 받은 메일 중 회신이 필요한 것을 정리해줘"
2일정 확인"이번 주 일정 중 겹치는 것을 알려줘"
3보고서 초안"회의 내용으로 보고서 초안을 만들어줘"
4문서 점검"문서 검토 에이전트로 오탈자와 숫자를 점검해줘"

폰으로 지시하기

사무실 PC에서 앱을 켜 두고 폰의 Claude 앱으로 작업을 지시하고 승인할 수 있습니다 (Dispatch는 Pro/Max 플랜, Remote Control은 관리자 설정 필요).

음성 지시는 사전 테스트 후 시연합니다. 발송·수정·삭제는 승인 후 실행하는 설정을 권장합니다.
9토의: 그룹 전체 조직도 재구성20분

진행 방식

발표가 아닌 임원 토의입니다. AI는 초안과 비교표를 빠르게 만드는 도구로 활용합니다.

논의 질문

  • 현재 조직도에서 업무가 겹치거나 비어 있는 곳은 어디인가
  • 계열사 공통 기능과 개별 기능을 어떻게 나눌 것인가
  • 결재선과 시스템(ERP) 권한을 조직도와 어떻게 맞출 것인가
  • 개편 시기와 단계는 어떻게 잡을 것인가

AI 활용 흐름

단계내용
1현황 정리 (조직·업무 범위)
2재구성안 2~3개 초안
3안별 장단점 비교표
4임원 결정 후 상세안 작성
조직도에는 인사 정보가 포함됩니다. 이 자료에는 개인 이름을 넣지 않았으며, 실제 조직도 작업 시에는 대외비 표기와 접근 제한을 적용합니다.
