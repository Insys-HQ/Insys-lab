제주 U밴드(439MHz대) 중계기: DUP- 5.000MHz + 톤 88.5Hz

톤 88.5Hz 설정

중계기는 서브톤(CTCSS)이 실린 신호에만 반응합니다. 톤을 켜지 않으면 중계기가 열리지 않습니다.

공장 기본값이 이미 88.5Hz입니다. 대부분 TONE만 켜면 끝납니다.

① 톤 켜기 (매뉴얼 Repeater operation)

  1. MENU를 눌러 메뉴 모드로 들어갑니다.
  2. DIAL을 돌려 TONE을 선택하고 DIAL을 눌러 다음 단계로 갑니다.
  3. DIAL을 돌려 TONE(중계기 톤)을 선택합니다. 화면에 T가 나타납니다.
  4. DIAL을 눌러 값을 확정하고, MAIN BAND를 눌러 메뉴를 종료합니다.
  5. 이후 송신하면 서브톤이 신호에 함께 실립니다.

② 톤 주파수 확인·변경

경로: MENU → EXMENU → EXMEN-DUP.T → R TONE

항목설정값설명
TONETONE송신에 서브톤을 실음 (중계기 접속용). 화면 T
R TONE88.5접속 톤. 50개 CTCSS 중 선택(67.0~254.1), 기본 88.5
TSQL선택상대 톤이 맞을 때만 소리가 남. 수신 톤은 C TONE(기본 88.5)

톤 종류 한눈에

종류동작
OFF톤 사용 안 함
TONE송신에만 톤을 실음 → 중계기 접속에 사용
TSQL송신에 톤을 싣고, 같은 톤이 오는 신호만 수신(소리)

스플릿 톤: 송신 톤(R TONE)과 수신 톤(C TONE)을 채널별로 따로 설정할 수 있습니다.

U밴드 +/- (듀플렉스) 상세

왜 +/- 설정이 필요한가

중계기는 한 주파수로 신호를 받아(입력) 다른 주파수로 다시 내보냅니다(출력). 내 무전기는 출력 주파수로 수신하고 입력 주파수로 송신해야 합니다. 이 둘의 간격이 오프셋, 어느 쪽이 높은지가 방향(+/-)입니다.

한국 439MHz대: 송신이 수신보다 5MHz 낮음 → DUP- / 오프셋 5.000MHz
예) 수신(출력) 439.680 → 송신(입력) 434.680

설정 순서 (화면 우측 MAIN 밴드 기준)

  1. MAIN BAND로 UHF(439MHz)가 있는 밴드를 MAIN으로 선택
  2. V/MHz SCAN으로 VFO 모드, 모드는 FM 확인
  3. DIAL로 수신 주파수를 중계기 출력 주파수에 맞춤 (예: 439.680)
  4. MONI DUP을 길게 눌러 듀플렉스 방향 화면을 띄움
  5. DIAL을 돌려 DUP- 선택 OFF=단신(simplex) / DUP-=송신이 낮음 / DUP+=송신이 높음
  6. MONI DUP을 눌러 방향 확정 → 화면에 DUP- 표시
  7. 오프셋 확인: MENU → DIAL 돌려 OFFSET → DIAL 눌러 진입 → DIAL로 5.000 맞춤 → DIAL 눌러 확정 → MAIN BAND로 종료 오프셋은 VFO 튜닝 스텝 단위로 바뀝니다. 5MHz까지 돌리기 어려우면 먼저 스텝(TS)을 크게 바꾸세요.
  8. 톤 설정(톤 88.5 탭)까지 마치면 송신 준비 완료

방향 선택값

표시의미이 경우
OFF수신·송신 같은 주파수 (단신)직접 교신(simplex)
DUP-송신 = 수신 − 오프셋U밴드 중계기
DUP+송신 = 수신 + 오프셋일부 VHF 중계기 등

오프셋 기본값은 밴드·버전마다 다릅니다(0.600 등). 범위는 0~59.995MHz이므로 U밴드는 5.000으로 직접 입력해야 합니다.

자동 중계기 기능 (AUTORP) 한국 사양

  • 경로: MENU → EXMENU → AUTORP (OFF/ON)
  • ON이면 중계기 출력 주파수 범위에 들어갈 때 듀플렉스를 자동 설정하며, 수동 듀플렉스 설정보다 우선합니다. 이때는 위 4~7단계가 필요 없을 수 있습니다.
  • 자동 설정값이 해당 중계기와 다르면 AUTORP를 OFF로 두고 수동 설정하세요.
  • 자동 설정이 적용되는 주파수 범위와 방향 표는 매뉴얼 Auto Repeater 항목(p.57 부근)에서 확인하세요.

오프밴드 표시

송신(PTT)했을 때 화면에 OFF가 뜨면 송신 주파수가 아마추어 대역을 벗어난 것입니다. 방향과 오프셋을 다시 확인하세요.

제주 개별 중계기 주파수·톤은 미확인입니다. 검색어: "제주 아마추어무선 중계소 439MHz", "KARL 중계기 현황", "RCNET 제주"
