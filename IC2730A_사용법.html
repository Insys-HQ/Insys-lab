U밴드 광역망 교신: 수신 439.680 / 송신 434.680 = DUP- 5.000MHz + 톤 88.5Hz

U밴드 광역망 설정

수신(중계기 출력) 439.680MHz
송신(중계기 입력) 434.680MHz = 439.680 − 5.000
항목설정값비고
수신 주파수439.680VFO 모드에서 DIAL로 입력
듀플렉스 방향DUP-송신이 수신보다 낮음
오프셋5.000MHz송신 = 434.680
톤TONE / R TONE 88.5화면 T 표시
모드·스텝FM · 5.0kHz기본값. 439.680은 5kHz 배수라 그대로 입력 가능
V밴드(좌측 145.000)는 건드리지 않습니다. 모드·스텝·톤·오프셋은 MAIN 밴드에만 적용되므로, 우측 U밴드가 MAIN일 때 설정하면 V밴드 설정은 그대로입니다. 사진 화면은 우측 U밴드(439.680)가 MAIN(MAIN 표시)입니다.

설정 순서

  1. MAIN 밴드 확인: 우측 U밴드에 MAIN 표시가 있는지 확인. 없으면 우측 MAIN BAND 키를 누름
  2. VFO 모드, 수신 주파수 입력: V/MHz SCAN으로 VFO 모드 → DIAL을 돌려 439.680에 맞춤 다이얼을 빨리 돌리면 가속됩니다(FUNC-DIAL S 기본 ON).
  3. AUTORP 확인(아래 박스 참고): 한국 기본 ON이면 이 단계에서 DUP-가 자동으로 뜰 수 있음
  4. 방향 DUP- 설정(자동으로 안 뜰 때): MONI DUP을 1초 이상 길게 → DIAL로 DUP- → MONI DUP 눌러 확정
  5. 오프셋 5.000 설정: 경로는 아래 배너. MENU → EXMENU → DUP.T → OFFSET에서 DIAL로 5.000 → DIAL 눌러 저장 → MAIN BAND로 종료
  6. 톤 켜기: MENU → EXMENU → DUP.T → TONE에서 TONE 선택 → 저장 → 종료. 화면에 T 표시
  7. 톤 주파수 확인: DUP.T → R TONE이 88.5인지 확인 (공장 기본값이 88.5)
  8. 최종 확인: 화면 우측에 439.680, DUP-, T가 보이면 완료. 송신 주파수는 계산상 434.680

메뉴 경로

방향 MONI DUP(길게) › DIAL로 DUP- › MONI DUP 오프셋 MENU › EXMENU › EXMEN-DUP.T › DUP.T-OFFSET › 5.000 톤 켜기 MENU › EXMENU › EXMEN-DUP.T › DUP.T-TONE › TONE 톤 주파수 MENU › EXMENU › EXMEN-DUP.T › DUP.T-R TONE › 88.5

메뉴 안에서는 DIAL을 돌려 선택하고 DIAL을 눌러 다음 단계·저장, MAIN BAND로 종료합니다. 한 항목의 기본값 복원은 값 선택 화면에서 MR CALL을 길게 누릅니다.

방향 선택값

표시의미이 경우
OFF수신·송신 같은 주파수 (단신)직접 교신
DUP-송신 = 수신 − 오프셋U밴드 광역망
DUP+송신 = 수신 + 오프셋일부 VHF 중계기 등
자동 중계기(AUTORP) MENU › EXMENU › EXMEN-FUNC › FUNC-AUTORP › ON / OFF한국 사양 기본 ON. FM에서 중계기 출력 주파수 범위로 들어가면 듀플렉스를 자동으로 켜고 끄며 수동 설정보다 우선합니다. 오프셋과 R TONE은 자동으로 바뀌지 않습니다. 이 설정은 밴드별 항목이 아니라 무전기 전체 설정이어서, V밴드에도 같은 규칙이 적용될 수 있습니다. V밴드 설정을 절대 바꾸고 싶지 않으면 OFF로 두고 위 4번을 수동으로 하세요.

채널 전환

가정: "2CH 리그"를 좌·우 2개 밴드(V/U)를 가진 이 무전기로 보고, ① V↔U 밴드 전환, ② U밴드 광역망 설정을 메모리 채널에 저장해 전환하는 방법을 정리했습니다. 다른 뜻(예: 광역망 2개 채널 운용)이면 알려주세요.

① 밴드 전환 (V ↔ U)

  • 양쪽 밴드는 각자 VOL, SQL, DIAL을 가집니다.
  • U밴드로 전환: 우측 MAIN BAND 키 → 우측에 MAIN 표시
  • V밴드로 전환: 좌측 MAIN BAND 키 → 좌측에 MAIN 표시
  • MAIN 밴드가 설정(메뉴)과 송신의 대상입니다 확인필요. 메뉴 설정 전에는 항상 U밴드가 MAIN인지 확인하세요.
MAIN 밴드 키로 좌·우를 바꿔도 각 밴드에 설정된 주파수·톤·오프셋은 따로 유지됩니다. 광역망 설정을 한 번 해두면 V밴드를 쓰다 돌아와도 그대로입니다.

② 광역망 설정을 메모리 채널에 저장

U밴드 설정(수신 439.680 · DUP- · 5.000 · 톤 88.5)을 마친 상태에서 진행합니다.

  1. U밴드가 MAIN이고 VFO 모드에서 설정이 화면에 표시된 상태인지 확인
  2. MW를 눌러 메모리 입력 화면 표시 매뉴얼
  3. DIAL로 WRITE 선택 → DIAL 누름 매뉴얼
  4. OVERW?가 나오면 DIAL로 YES → DIAL 누름. 삐 소리가 나고 VFO 모드로 돌아옴 매뉴얼

저장할 채널 번호를 고르는 방법과 방향·오프셋이 함께 저장되는지는 본문 확인이 필요합니다 확인필요 (IC-2730E/A 매뉴얼 p.35 "Writing Into a Memory or Call Channel"). 톤은 채널별로 따로 저장되는 것이 제품 사양입니다.

채널 이름 붙이기 (최대 6자)

  1. 이름을 붙일 메모리 채널 선택
  2. MW → DIAL로 EDIT → DIAL 누름
  3. DIAL로 NAME → DIAL 누름
  4. DIAL로 글자 선택, ◄ ►로 커서 이동 (CLR은 글자 삭제, 글자 미선택 상태에서 ►는 빈칸)
  5. 완성 후 DIAL 누름 → WRITE → OVERW?에서 YES → 삐 소리 후 VFO로 복귀 매뉴얼
이름 표시 켜기 MENU › EXMENU › EXMEN-DISP › DISP-NAME › ON

③ 저장한 채널로 전환

  1. MR CALL을 눌러 메모리 모드로 진입 확인필요
  2. DIAL을 돌려 저장한 채널 선택 (화면에 채널 번호, 이름 표시를 켰다면 이름 표시)
  3. VFO(직접 입력)로 돌아갈 때: V/MHz SCAN 확인필요

공통 조작법 (진입 → 값 변경 → 종료)

  1. MAIN BAND로 설정할 밴드를 MAIN으로 선택 MODE, TS, TONE, OFFSET, R TONE, C TONE, CODE, DTCS-P와 스캔 항목(PRIO~B-LINK)은 MAIN 밴드에 적용됩니다.
  2. MENU를 눌러 메뉴 진입
  3. DIAL로 EXMENU 선택 → DIAL을 눌러 다음 단계
  4. DIAL로 그룹 선택(예: FUNC) → DIAL 누름
  5. DIAL로 항목 선택(예: MIC G) → DIAL 누름 (선택값 표시)
  6. DIAL로 값 선택 → DIAL을 눌러 저장하고 한 단계 위로
  7. MAIN BAND(또는 V/MHz SCAN, MR CALL)를 눌러 메뉴 종료

한 항목을 기본값으로 되돌리려면 값 선택 화면에서 MR CALL을 길게 누릅니다.
