제주 U밴드(439MHz대) 중계기: DUP- 5.000MHz + 톤 88.5Hz

톤 88.5Hz 설정

중계기는 서브톤(CTCSS)이 실린 신호에만 반응합니다. 톤을 켜지 않으면 중계기가 열리지 않습니다.

공장 기본값이 이미 88.5Hz입니다(R TONE·C TONE 모두). 대부분 TONE만 켜면 끝납니다.

① 톤 켜기

MENU › EXMENU › EXMEN-DUP.T › DUP.T-TONE › TONE
  1. (필요 시) MAIN BAND로 설정할 밴드를 MAIN으로 선택 톤·오프셋은 MAIN 밴드에 적용됩니다.
  2. MENU를 눌러 메뉴 모드로 진입
  3. DIAL을 돌려 EXMENU 선택 → DIAL을 눌러 다음 단계
  4. DIAL로 DUP.T 그룹 선택 → DIAL 누름
  5. DIAL로 TONE 항목 선택 → DIAL 누름 (선택값 표시)
  6. DIAL로 TONE 선택 → DIAL 눌러 저장. 화면에 T 표시
  7. MAIN BAND를 눌러 메뉴 종료

매뉴얼 Repeater operation에는 상위 메뉴의 TONE 항목으로 같은 설정을 하는 방법도 나옵니다 (MENU → DIAL로 TONE → DIAL 눌러 TONE 선택 → MAIN BAND로 종료).

② 중계기 톤 주파수 88.5 확인·변경

MENU › EXMENU › EXMEN-DUP.T › DUP.T-R TONE › 88.5

같은 방식으로 항목에서 R TONE 선택 → DIAL 누름 → DIAL로 88.5 → DIAL 눌러 저장 → MAIN BAND 종료. 기본값 복원은 값 선택 화면에서 MR CALL을 길게 누릅니다.

R TONE88.5접속 톤. 50개 CTCSS 중 선택(67.0~254.1), 기본 88.5

U밴드 +/- (듀플렉스) 상세

왜 +/- 설정이 필요한가

중계기는 한 주파수로 신호를 받아(입력) 다른 주파수로 다시 내보냅니다(출력). 내 무전기는 출력 주파수로 수신하고 입력 주파수로 송신해야 합니다. 이 둘의 간격이 오프셋, 어느 쪽이 높은지가 방향(+/-)입니다.

한국 439MHz대: 송신이 수신보다 5MHz 낮음 → DUP- / 오프셋 5.000MHz
예) 수신(출력) 439.680 → 송신(입력) 434.680

① 방향(DUP-) 설정 — 메뉴가 아닌 전용 키

MONI DUP(길게) › DIAL로 DUP- › MONI DUP(누름)
  1. MAIN BAND로 UHF 밴드를 MAIN으로 선택, V/MHz SCAN으로 VFO 모드, 모드는 FM 확인 모드는 EXMEN-MOD.TS › MOD.TS-MODE.
  2. DIAL로 수신 주파수를 중계기 출력 주파수에 맞춤 (예: 439.680)
  3. MONI DUP을 1초 이상 길게 눌러 듀플렉스 방향 화면을 띄움 (VFO 모드에서)
  4. DIAL을 돌려 선택 OFF=단신 / DUP-=송신이 낮음 / DUP+=송신이 높음
  5. MONI DUP을 눌러 확정 → 화면에 DUP- 표시

② 오프셋 5.000MHz 설정

MENU › EXMENU › EXMEN-DUP.T › DUP.T-OFFSET › 5.000
  1. MENU → DIAL로 EXMENU → DIAL 누름
  2. DIAL로 DUP.T → DIAL 누름 → DIAL로 OFFSET → DIAL 누름
  3. DIAL을 돌려 5.000에 맞춤 (범위 0~59.995MHz, 기본 0.600 등 밴드·버전별)
  4. DIAL을 눌러 저장 → MAIN BAND로 종료

매뉴얼 Duplex Operation에는 상위 메뉴 OFFSET(MENU → DIAL로 OFFSET → DIAL 누름 → 값 → DIAL 누름 → MAIN BAND)으로 설정하는 방법도 있습니다.

오프셋은 VFO 튜닝 스텝 단위로 바뀝니다. 스텝 설정: MENU › EXMENU › EXMEN-MOD.TS › MOD.TS-TS 선택값은 5, 6.25, 10, 12.5, 15, 20, 25, 30, 50kHz입니다. 5MHz까지 돌리기 어려우면 스텝을 키우세요. FUNC-DIAL S(다이얼 가속, 기본 ON)가 켜져 있으면 빠르게 돌릴수록 크게 움직입니다.

방향 선택값

표시의미이 경우
OFF수신·송신 같은 주파수 (단신)직접 교신(simplex)
DUP-송신 = 수신 − 오프셋U밴드 중계기
DUP+송신 = 수신 + 오프셋일부 VHF 중계기 등

자동 중계기 기능 (AUTORP) 한국 사양

MENU › EXMENU › EXMEN-FUNC › FUNC-AUTORP › ON / OFF
  • 한국 사양은 기본 ON입니다. FM에서 중계기 출력 주파수 범위로 들어가면 듀플렉스를 자동으로 켜고 끕니다. 수동 듀플렉스 설정보다 우선합니다.
  • 오프셋과 중계기 톤(R TONE)은 자동으로 바뀌지 않습니다. 그래서 ②의 오프셋 5.000과 R TONE 88.5는 직접 맞춰야 합니다.
  • AUTORP가 켜져 있으면 ①이 필요 없을 수 있습니다. 주파수를 맞춘 뒤 화면에 DUP-가 뜨는지 확인하세요.
  • 자동 설정이 적용되는 주파수 범위와 방향 표는 매뉴얼 Auto Repeater 항목(p.57 부근)에서 확인하세요.
  • 자동 설정이 해당 중계기와 맞지 않으면 OFF로 두고 ①을 수동으로 하세요.

오프밴드 표시

송신(PTT)했을 때 화면에 OFF가 뜨면 송신 주파수가 아마추어 대역을 벗어난 것입니다. 방향과 오프셋을 다시 확인하세요.

제주 개별 중계기 주파수·톤은 미확인입니다. 검색어: "제주 아마추어무선 중계소 439MHz", "KARL 중계기 현황", "RCNET 제주"

공통 조작법 (진입 → 값 변경 → 종료)

  1. MAIN BAND로 설정할 밴드를 MAIN으로 선택 MODE, TS, TONE, OFFSET, R TONE, C TONE, CODE, DTCS-P와 스캔 항목(PRIO~B-LINK)은 MAIN 밴드에 적용됩니다.
  2. MENU를 눌러 메뉴 진입
  3. DIAL로 EXMENU 선택 → DIAL을 눌러 다음 단계
  4. DIAL로 그룹 선택(예: FUNC) → DIAL 누름
  5. DIAL로 항목 선택(예: MIC G) → DIAL 누름 (선택값 표시)
  6. DIAL로 값 선택 → DIAL을 눌러 저장하고 한 단계 위로
  7. MAIN BAND(또는 V/MHz SCAN, MR CALL)를 눌러 메뉴 종료

한 항목을 기본값으로 되돌리려면 값 선택 화면에서 MR CALL을 길게 누릅니다.
