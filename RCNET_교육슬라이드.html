A 개요

시스템 구성 — HRI-200 방식 vs PDN 방식

🏠 HRI-200 방식 (DS0ARC)

  • HRI-200 장비 + CT-174 케이블 + FTM-510D + PC
  • Room 개설 가능 (Room Host)
  • HRI200 드라이버 추가 설치 필요
  • 켤 때 GM+DG3 누른 채 전원 ON

📱 PDN 방식 (봉사원·이동국)

  • FTM-510D + SCU-58 케이블 + 노트북 (HRI-200 불필요)
  • Room 개설 불가 · Room 접속·교신 가능
  • 유심 라우터 인터넷 · 차량/현장 이동 운용 가능
  • 그냥 전원 ON → DX 길게

B 사전 준비

YAESU 멤버 등록 — 공통 4단계

  1. Radio ID 확인 — PDN은 FTM-510D에서 직접, HRI-200은 본체 뒷면 S/N 스티커영문 대소문자 정확히 구별 (A ≠ a)
  2. 멤버 등록 — 등록 페이지에서 이메일 → 메일 URL → 약관 동의 → 양식 입력 (콜사인, Radio ID, SEOUL/Seoul/Korea)
  3. 승인 메일 수신 (2~3 영업일) — User ID · Password · Node ID · Room ID(5자리)를 안전하게 보관
  4. 소프트웨어 다운로드 — 로그인 후 Node owner 페이지 → WIRES-X_setup.exe (HRI-200만 HRI200_driver_setup.exe 추가)
주의 : Radio ID를 잘못 입력하면 승인 후에도 접속이 되지 않습니다. 승인 메일의 비밀번호는 타인과 공유하지 마세요.

B 사전 준비

Radio ID 확인 — FTM-510D · FT5D

📻 FTM-510DR/DE (노드국)

  1. GM 버튼 누름 → 파란 "GM" 화면
  2. FUNC 노브로 61 RADIO ID 선택59=DP-ID LIST · 60=RANGE RINGER · 62=LOG LIST
  3. FUNC 노브 누름 → 화면 하단에 5자리 표시

📱 FT5DR/DE (봉사원 핸디)

  1. F MENU 길게 누름
  2. 빨간 GM 터치
  3. DIAL로 2 RADIO ID CHECK 선택·터치
  4. 영문+숫자 5자리 표시 (대소문자 구분)
Radio ID는 편집할 수 없는 고유 번호입니다. 사진을 찍어 두거나 정확히 메모하세요.

C PDN 운용 (봉사원)

룸 접속과 교신 — 조작은 무전기에서

PDN은 소프트웨어가 아닌 FTM-510D 무전기에서 룸에 접속합니다.

방법 2 · Search & Direct (권장)

  1. DX 길게(1~2초) → X 아이콘 고정
  2. FUNC 노브 누름 → Search & Direct 선택
  3. 숫자 키패드로 48182 입력
  4. RCNet-Disaster 선택 → FUNC 누름 → Connect

방법 1 · ALL 목록

  1. DX 길게 → X 아이콘 고정
  2. FUNC 노브 → ALL 선택
  3. 목록에서 RCNet-Disaster → Connect

접속 후 화면에 "RCNet-Disaster" 확인 → PTT 교신

DX를 짧게 누르면 AMS↔DN↔FM 모드만 전환됩니다. 반드시 길게 누르세요.

FT5D — C4FM 디지털 모드 설정 (최초 1회)

FT5D는 PC·케이블 없이 무전기 단독으로 WIRES-X 룸 접속 가능. WIRES-X는 A-밴드에서만 동작합니다.

주파수·모드

  1. A-밴드(상단) 활성 확인
  2. DIAL로 145.620 MHz
  3. MODE 버튼 → DN(권장) 또는 AMS
  4. 화면 상단 DN/AMS 표시 확인

DG-ID 설정

  1. F MENU 길게
  2. WIRES-X → 5 DG-ID
  3. DIAL로 AUTO → BACK 저장AUTO = 노드 DG-ID에 자동 맞춤
FM 모드에서는 WIRES-X 디지털 룸 접속 불가(DTMF만 가능). 반드시 DN 또는 AMS로 설정하세요.

FT5D — WIRES-X 룸 접속

DS0ARC 노드(145.620MHz)의 전파 수신 범위 안에서, DS0ARC가 ONLINE일 때만 접속됩니다.

① Search & Direct

  1. GM/X 1~2초 길게 → X 고정
  2. SEARCH & DIRECT 터치
  3. 룸 ID 48182 입력
  4. RCNet-Disaster 터치 → PTT

② 즐겨찾기 (C1~C5)

  1. 접속 상태에서 룸명 터치 → ADD
  2. 카테고리(예: C1) 저장
  3. 다음부터 GM/X 길게 → C1 터치

③ 최근 룸 재접속

  1. GM/X 길게 → 노드 접속
  2. 하단 이전 룸명 깜박임 터치
  3. 가장 빠름 — 매번 권장
해제 : BACK → Disconnect, 이어서 GM/X 1~2초 길게 → X 아이콘 소멸 → 일반 VFO 복귀

Modulation 변경 — DIGITAL ↔ FM

ONLINE 중에는 Modulation 항목이 회색(변경 불가). 아래 순서를 지켜야 합니다.
  1. Disconnect로 룸 접속 해제
  2. 소프트웨어 OFFLINE 전환
  3. FTM-510D 전원 OFF
  4. 소프트웨어 File → Exit (트레이 아이콘까지 종료)
  5. 소프트웨어 재실행 → COM 포트 선택 → OK
  1. 무전기 OFF 상태에서 File → Settings → Transceiver
  2. Modulation 선택FM–FM : 아날로그 핸디용 / DIGITAL–DIGITAL : C4FM용
  3. Apply → OK
  4. FTM-510D 전원 ON → ONLINE 확인
WIRES-X는 AUTO 모드가 없어 C4FM과 아날로그를 동시에 수용할 수 없습니다 → 2노드 운용(27번 슬라이드) 권장

아날로그 핸디 → 노드 접속 (DTMF)

  1. 핸디 설정 : 145.620 MHz · 모드 FM · CTCSS/TONE 없음
  2. 노드 ONLINE(IPv4) 확인
  3. PTT를 누른 채 키패드로 #55555 입력 → 마지막 5 후 1~2초 유지 후 해제
  4. 핸디 스피커에서 "삐~" 접속 완료 톤 확인 → RCNet-Disaster 접속
  5. PTT로 교신 · 종료는 PTT 누른 채 * 입력
노드 응답이 없으면 : PTT를 너무 빨리 뗐는지, 주파수가 정확히 145.620MHz인지, FM 모드인지 확인하세요.

기종별 DTMF 전송 방법

🔵 ICOM · IC-V86 / IC-T10

  1. 사전 설정 : Set Mode → DTMF TX → MAN기본 AUTO면 직접 입력 불가
  2. PTT 누른 채 # 5 5 5 5 5
  3. 마지막 후 1~2초 유지

🟡 YAESU · FT-60R / 65R / VX-6R

  1. 별도 설정 불필요
  2. PTT 누른 채 # 5 5 5 5 5
  3. 마지막 후 PTT 유지 → 해제

🔴 Baofeng · UV-5R / 82 / K5

  1. 사전 설정 : MENU → 16 DTMFST → OFF안 하면 마이크 음이 섞임
  2. PTT 누른 채 # 5 5 5 5 5
  3. UV-82는 상단 PTT 사용
