A 공통 설정

A-1 YAESU 멤버 등록과 로그인 (최초 1회)

  1. Radio ID 확인 — HRI-200은 본체 뒷면 S/N, PDN은 무전기에서 직접영문 대소문자 정확히 구별
  2. 멤버 등록 — 이메일 → 메일 URL → 약관 동의 → 콜사인·Radio ID·City(SEOUL/Seoul/Korea) 입력
  3. 승인 메일 수신 (2~3 영업일) — User ID · Password · Node ID · Room ID(5자리)를 보관
  4. 로그인 — WIRES-X 사이트 우측 상단 Member Login
🔒 로그인 필요 : YAESU 멤버 로그인이 필요한 페이지입니다. 로그인하지 않으면 해당 화면으로 연결되지 않고 로그인 화면이 나옵니다. 먼저 WIRES-X 사이트 → Member Login으로 로그인한 뒤 링크를 다시 누르세요.

ID Entry 절차

  1. 무전기 연결·ON → Radio ID 자동 입력 확인
  2. DTMF ID Node · Room 입력, 나머지 입력
  3. ID Entry 클릭 → 완료 메시지 → OK
노드별로 다른 값은 Radio ID와 DTMF ID뿐입니다. 이후 단원은 이 값을 반복하지 않습니다.

Access Point

무전기를 로컬 기지국으로 사용 — 인근 무선국이 RF로 접속해 인터넷으로 연결됩니다.

Direct Operation

  1. WIRES-X 소프트웨어 실행 → Portable HRI 모드 선택, COM 포트 Prolific USB-to-Serial Comm Port (COMx) 선택

D 교신 방법

D-1 아날로그 무전기로 교신하기

  1. 무전기를 FM, 노드 주파수로 설정 (CTCSS/TONE 없음)
  2. PTT를 누른 채 # + 5자리 ID 입력 — 룸 #48182 · 또는 노드에 설정된 룸에 #55555
  3. PTT를 놓고 약 10초 수신 대기 → 소리가 들리면 접속 (접속 화면은 나타나지 않음)
  4. PTT로 교신
  5. 종료 : PTT를 누른 채 #99999
DTMF동작노드 쪽 설정
#+5자리해당 룸/노드에 접속—
#55555지정한 룸(Return to Room)에 접속Call settings의 DTMF #55555 ☑
#66666노드 상태 음성 안내General settings의 DTMF #66666 ☑
#99999 · *접속 해제*는 DTMF * Disconnect ☑

D 교신 방법

D-2 기종별 DTMF 사전 설정

🔵 ICOM · IC-V86

  1. Set mode의 DTMF TX key 항목에서 DTMF 송출 방식 선택

🟡 YAESU · FT-65R

  1. Set Mode 12 DTMF SET → MANUAL (기본값)

🔴 Baofeng · UV-5R / UV-82

  1. MENU → 16 DTMFST → OFF사이드톤이 마이크로 들어가 DTMF를 왜곡할 수 있음
설정 후 입력 방법은 모두 같습니다 — PTT를 누른 채 # + 5자리 (D-1).
D 교신 방법

D-3 FT5로 교신하기

FM 모드 — HRI-200 · PDN(FM) 노드

  1. A-밴드를 노드 주파수로 맞춤 (WIRES-X는 A-밴드 전용)
  2. [MODE] 터치 → 아날로그 FM
  3. PTT를 누른 채 [DTMF] 터치 → # + 5자리 입력
  4. PTT를 놓고 약 10초 대기 → 소리 확인 (접속 화면 없음)
  5. 해제 : PTT + [DTMF] → #99999

C4FM(DN) — 디지털 노드

  1. DG-ID를 노드와 같은 번호로 설정
  2. GM/X 길게 → 노드 발견 시 X 점등
  3. SEARCH & DIRECT → [ID]로 5자리 입력
  4. 해제 : 매뉴얼의 해제 절차 참조
C4FM 해제 키 조작 등 세부 버튼은 FT5DR 매뉴얼 링크의 해당 장을 확인하세요.
