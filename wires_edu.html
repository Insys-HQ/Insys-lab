YAESU C4FM · WIRES-X · PDN · MMDVM 교육 및 구축 가이드

목적: 대한적십자사 서울지사 재난대응 하이브리드 무선망과 개인 C4FM 연구용 시스템을 이해하기 위한 교육자료입니다.

검증 원칙: YAESU 공식 최신 노드 안내, 공식 매뉴얼 및 MMDVM 공식 프로젝트 자료를 우선했습니다. 공식 자료로 확인되지 않는 기능은 사실로 단정하지 않고 현장 검증 필요로 표시했습니다.

중요한 정정
이전 설명에서 "PDN이면 아날로그 FM도 자동으로 인터넷으로 전달된다"는 식으로 단정한 부분은 정확하지 않습니다. YAESU는 Portable Digital Node Mode와 Portable HRI Mode를 구분합니다. 아날로그 FM을 인터넷망과 연계하려면 Portable HRI Mode를 검토해야 합니다. 또한 "LTE가 연결되면 3개 거점이 자동으로 아날로그 중계기가 된다"는 것도 실제 설정과 시험으로 확인해야 합니다.

4. HRI-200과 WIRES-X Host

YAESU의 최신 WIRES-X 노드 안내에서는 HRI-200 노드를 PC + HRI-200 + 대응 트랜시버로 구성하고, 인터넷과 무선을 연결하는 WIRES-X 노드로 설명합니다.

신월동 Host 목표 구성
FTM-510D + HRI-200 + Windows PC + LTE 인터넷을 이용하여 WIRES-X Host/Node를 구성하고 Room을 운영하는 중심 노드로 사용하는 구조입니다.

최신 YAESU 안내는 WIRES-X PC Software Ver.2.000 이상, Windows 11, RAM 4GB 이상, 저장공간 64GB 이상, USB 2.0, 유선 LAN 권장 및 8Mbps 이상의 인터넷 회선을 제시합니다.

6. PDN의 두 운용 방식

6-1. Portable Digital Node Mode

YAESU는 이 방식을 C4FM 디지털 통신만 인터넷과 연결하는 방식으로 설명합니다. Direct Operation에서는 PC에 연결된 무전기의 마이크 신호가 PC와 인터넷으로 전달되고 인터넷 신호는 해당 무전기 스피커에서 들립니다. 이 모드에서는 해당 PDN 무전기가 공중 RF로 송수신하지 않는다고 명시합니다.

중요: 145.620MHz 아날로그 봉사원 통신을 인터넷망과 연계하려는 목적이라면 Portable Digital Node Mode만으로는 부족합니다.

6-2. Portable HRI Mode

YAESU는 Portable HRI Mode를 C4FM Digital과 Analog FM 모두 인터넷과 통신할 수 있는 방식으로 설명합니다.

Access Point 운용에서는 별도의 로컬 C4FM 무전기가 PDN 무전기와 RF로 통신하고, PDN 무전기가 로컬 C4FM/Analog 신호를 인터넷으로 전달하며 인터넷에서 온 Node/Room 신호를 로컬 무전기로 송신하는 구조를 설명합니다.

적십자 시스템에서 핵심 확인사항:
마장동과 이동차에서 145.620MHz 아날로그 봉사원 통신까지 WIRES-X 인터넷망과 연계하려면 FTM-510D의 Portable HRI Mode / Access Point 운용이 목표 구조에 맞는지 실제 설정으로 확인해야 합니다.

출처: YAESU WIRES-X PDN Function Manual

8. 재난 발생 시 활용

  1. 이동통신차가 현장으로 출동합니다.
  2. 현장 봉사원들은 145.620MHz 아날로그 FM으로 직접 교신합니다.
  3. 현장 접근 봉사원이 이동통신차의 RF 도달권에 들어오면 직접 교신합니다.
  4. 원거리 봉사원이 신월동 또는 마장동과 RF 교신이 가능하면 해당 거점을 통한 통신 경로를 확보하는 것이 목표입니다.
  5. 그 RF 통신을 LTE/WIRES-X를 통해 이동통신차까지 연결하는 기능은 실제 Portable HRI/Access Point 설정으로 검증합니다.
금지해야 할 단정: "3개의 FTM-510D가 같은 주파수에서 자동으로 중계기가 된다."
정확한 표현은 "RF와 WIRES-X 인터넷 경로를 설정하여 원하는 브리지 기능을 구현하고 실제 통신 경로를 시험한다"입니다.

9. 매주 화요일 21시 정기교신

145.620MHz 아날로그 FM 정기교신은 주간 통신망 점검훈련으로 활용할 수 있습니다.

  • 봉사원 무전기 정상 여부
  • 지역별 RF 도달상태
  • 3개 거점 노드 상태
  • LTE 연결상태
  • 인터넷 브리지 경로
  • 재난 시 통신 숙련도

11. 직접 RF와 LTE 연결

① 직접 RF
봉사원 ───── RF ───── 이동통신차

② 인터넷 경로
봉사원 ─ RF ─ 기지국 ─ WIRES-X ─ LTE ─ 이동통신차

두 경로가 동시에 존재할 수 있지만 같은 음성이 RF와 인터넷 경로를 모두 거쳐 다시 RF로 나오면 지연, 에코, 중복수신 또는 루프가 생길 수 있으므로 실제 시험이 필요합니다.

12. 개인 C4FM 연구망 — MMDVM

MMDVM은 Multi-Mode Digital Voice Modem 계열의 범용 디지털 모뎀입니다. MMDVMHost 공식 프로젝트는 MMDVM/DVMega와 네트워크 사이를 연결하며 D-Star, DMR, P25, NXDN, System Fusion(YSF), POCSAG, FM 등을 지원한다고 설명합니다.

또한 MMDVMHost는 32/64비트 Linux와 Windows(Visual Studio 2022, x86/x64)에서 빌드할 수 있다고 공식 프로젝트에 명시되어 있습니다.

15. 3,520원 LTE 요금제

월 3,520원이라는 가격만으로 "충분하다"고 판단하면 안 됩니다.
월 데이터 제공량, 소진 후 속도, LTE 라우터 사용 가능 여부, 테더링 제한, 통신망 등을 확인해야 합니다.

실제 투자 전 1회선을 먼저 개통하여 WIRES-X를 24~72시간 운용하고 데이터 사용량을 측정하는 것이 가장 안전합니다.

18. 최종 결론

확정적으로 이해할 내용
1. FTM-510D는 FM과 C4FM을 지원하는 VHF/UHF 무전기입니다.
2. WIRES-X는 YAESU의 인터넷 기반 시스템입니다.
3. HRI-200은 공식 WIRES-X 노드 구성에 사용하는 인터페이스입니다.
4. FTM-510D는 Portable Digital Node 대응 기종입니다.
5. Portable Digital Node Mode와 Portable HRI Mode는 기능이 다릅니다.
6. 아날로그 FM을 인터넷과 연계하려면 Portable HRI Mode/Access Point 운용을 검토해야 합니다.
7. MMDVMHost는 System Fusion/YSF를 지원하고 Linux와 Windows에서 운용할 수 있습니다.
투자 전에 반드시 실증할 내용
3개 거점의 FTM-510D가 145.620MHz 아날로그 통신을 어떤 방식으로 LTE/WIRES-X를 통해 상호 연결하고 RF로 재송신하는지는 단순 장비 연결만으로 보장된다고 가정하지 않습니다. 1개 노드 → 2개 노드 → 3개 노드 순으로 실제 시험한 후 최종 구축비를 집행합니다.
