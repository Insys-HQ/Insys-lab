## 1. 프로젝트 개요

28BYJ-48 스텝모터 3개 웹 제어 시스템(프로토타입)까지 완료한 상태에서, 실제 500g급 PCB를
반송·검사·분류하는 **선회팔 6축 자동화 장비**로 확장하는 단계다. 모터 6개 구동 상세는
이 채팅에서 새로 다룬다.

## 2. 장비 사양 및 동작 요구사항

- **기구 형태**: 선회팔(회전 베이스) 구조. 0~4번 위치가 회전반경 400mm 이내에 배치.
- **취급물**: PCB 기판, 약 500g.
- **축 구성**: 그리퍼 포함 6개 구동모터.
  - 6번째 축 = PCB를 집는 팔 그리퍼.
- **주변 장치**:
  - 컨베이어 벨트(폭 150mm, 길이 600mm) — PCB 투입 이송.
  - 투입센서 — 컨베이어 위 PCB 도착 감지.
  - 검사지그 클램프 그리퍼 — 평소 열림. PCB 안착 감지 시 자동으로 닫아 고정, 검사완료 시 자동 열림.
  - 지그 안착센서 — 지그에 PCB 놓임 감지.

## 3. 동작 시퀀스 (확정 해석)

1. START 신호 대기(홈 0번)
2. 컨베이어 구동 → PCB 투입 → 투입센서 감지(→컨베이어 정지)
3. 팔 0→1(투입) 이동 → 하강 → 그리퍼 닫기(집기) → 상승
4. 1→2(검사지그) 이동 → 하강 → 그리퍼 열기(안착) → 상승
5. 지그센서 감지 → **검사지그 클램프 자동 닫힘(PCB 고정)**
6. 팔 2→0 복귀
7. **검사완료 신호 대기**
8. 검사완료 수신 → **NG/OK 판정 화면 표시 + MES 전송** → **검사지그 클램프 자동 열림**
9. 팔 0→2 이동 → 하강 → 재파지(집기) → 상승
10. **판정 분류 배출**: OK → 3번, NG → 4번으로 이동 → 하강 → 열기(배출) → 상승
11. 팔 복귀(0번) → START 대기 → 전 과정 반복

> **미확정/확인 필요 사항**
> - 배출 방식: 현재는 "NG/OK 판정 기반 자동 분류(OK→3, NG→4)"로 확정. (원래 구두 설명의
>   "3번 놓고 다시 집어 4번" 순차 흐름을 판정 분류로 통합함)
> - 검사지그 클램프 구동: **전동(모터) vs 공압 실린더(솔레노이드)** 미정 → 이 채팅에서 결정 필요.
> - 6축의 정확한 관절 구성(θ베이스 / 팔신축 / Z / 손목 / 보조 / 그리퍼)은 기구 설계 확정 후 재정의.

## 4. 하드웨어 방향 (1차 검토안)

### 4-1. 축·액추에이터
| 구분 | 항목 | 1차 추천 |
|---|---|---|
| 선회팔 1축 | θ 베이스 회전 | NEMA 23 클로즈드루프 + 유성감속 10~20:1 |
| 선회팔 2축 | 팔 신축/엘보 | NEMA 23 클로즈드루프 |
| 선회팔 3축 | Z 승강 | NEMA 23 + 볼스크류(자립), 필요시 브레이크 |
| 선회팔 4축 | 손목 회전 | NEMA 17 |
| 선회팔 5축 | 보조축 | NEMA 17~23 |
| 선회팔 6축 | PCB 그리퍼 | NEMA 17 또는 전동 그리퍼 |
| 주변 | 컨베이어(150×600) | 소형 기어드 스텝(NEMA 17) 또는 기어드 BLDC |
| 주변 | 검사지그 클램프 | 소형 전동 그리퍼 또는 공압 실린더 |

> **핵심 원칙**: 토크 산정의 지배 인자는 부품 500g이 아니라 팔 무게·팔 길이(최대 400mm)·감속비·가속도다.
> 최종 모터 사양은 기구 CAD(팔 질량·무게중심·감속비·가감속 프로파일) 확정 후 재계산해야 한다.
> 반송 신뢰성을 위해 클로즈드루프 권장(탈조 방지).

### 4-2. 제어기
- **권장(국산·가성비)**: LS일렉트릭 XGB PLC (내장 최대 6축 펄스, 무료 XG5000). 축 확장은 EtherCAT.
- **대안**: 미쓰비시 FX3U 호환 6축 모션 PLC.
- **고급/확장**: Applied Motion MCA6 통합 모션 PLC(EtherCAT) + StepSERVO.
- **프로토타입만**: Arduino Mega + 외장 드라이버 (6축 동시·안전·MES 연동에는 부적합).

### 4-3. 필요 I/O
- 디지털 입력: START 버튼, 투입센서, 지그센서, 검사완료 접점, NG/OK 판정 접점, 각 축 원점/리밋.
- 출력: 6축 펄스·방향, 컨베이어 구동, 지그 클램프.
- 통신: MES 연동(Ethernet 기반 OPC-UA / Modbus TCP / EtherNet-IP).

## 6. 이 채팅에서 다룰 과제

1. 6축 각 모터의 정확한 토크·감속비 산정 (기구 파라미터 기반).
2. 제어기(PLC) 기종 확정 + I/O 배치표 + MES 연동 방식 확정.
3. 검사지그 클램프 구동 방식(전동/공압) 확정.
4. 배선/결선도, 안전(E-stop·인터록), 원점복귀 시퀀스.
5. (선택) 실제 PLC 로직(래더/ST) 초안.
